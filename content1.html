1. IS และ IT

ระบบสารสนเทศ (IS) คือระบบที่ รวบรวม จัดเก็บ ประมวลผล และส่งผ่านข้อมูล

องค์ประกอบความหมายตัวอย่าง
Hardwareอุปกรณ์คอมพิวเตอร์ เซิร์ฟเวอร์ IoT
SoftwareโปรแกรมOS แอปพลิเคชัน โปรแกรมวิเคราะห์ข้อมูล
Networkเครือข่ายอินเทอร์เน็ต LAN ไฟเบอร์ Wi-Fi 5G
Dataข้อมูลที่ใช้ในระบบข้อมูลลูกค้า ยอดขาย
Peopleบุคลากรในระบบผู้ใช้ ผู้ดูแลระบบ
Proceduresขั้นตอนการทำงานคู่มือ ขั้นตอนอนุมัติ
จำให้ได้: IT เป็นส่วนหนึ่งของ IS คือ Hardware + Software + Network + Data
